# Макет промостраницы «Новый год 2027» — Каменный цветок

Статичный HTML-макет по ТЗ (Google Doc «Разработка промостраницы „Новый год 2027“»).
Целевой адрес на сайте: https://kamenniy-cvetok.ru/new-year/

## Как открыть
```
cd new-year-2027 && python3 -m http.server 8765
# http://localhost:8765/          — с пометками для заказчика/контент-менеджера
# http://localhost:8765/?clean    — чистый вид без пометок
```

## Состав
- `index.html` — все блоки ТЗ: 4.1 Hero · 4.2 Атмосфера · 4.3 Тарифы (+таблица сравнения) · 4.4 Программа ·
  4.5 Банкет (+модалка «Посмотреть меню») · 4.6 1 января · 4.7 Активный отдых · 4.8 Карусель номеров ·
  4.9 Условия · 4.10 Раннее бронирование · Афиша 31.12–10.01 · финальный CTA · подвал.
- `css/styles.css` — стили, адаптив (1440 / 1024 / 860 / 640 и меньше).
- `js/app.js` — ссылки TravelLine, цели аналитики, меню, карусель, афиша, снег, sticky-кнопка.
- `img/` — логотип (цветной/светлый, без фона), фото номеров с сайта, `img/stock/` — временные фото.
- `credits.html`, `img/stock/CREDITS.json` — авторы и лицензии временных фото.

## Что подставить при внедрении
1. **TravelLine** — `js/app.js`, объект `BOOKING`: реальные ID тарифов «Новогодний» с банкетом / без банкета
   и категорий номеров; сверить имена URL-параметров с документацией модуля. Сейчас там заглушки
   (`NY2027_BANQUET`, `NY2027_BASE`, `ROOM_*`).
2. **Аналитика** — `ANALYTICS.ymId` (Метрика); GA4 подхватывается, если на странице есть `gtag`.
   Цели: `ny_book_header`, `ny_book_hero`, `ny_hero_choose`, `ny_book_tariff_banquet`, `ny_book_tariff_base`,
   `ny_book_banquet`, `ny_book_room` (+target), `ny_book_early`, `ny_book_final_banquet`, `ny_book_final_base`,
   `ny_book_sticky`, `ny_menu_view`.
3. **Фото** — заменить файлы в `img/stock/` на материалы с Яндекс.Диска (имена файлов оставить).
   Нужны: зимний hero, банкетный зал, гулянья (Завьялиха), баня, мануальная зона, прокат, шаттл.
4. **Меню банкета** — ссылка на PDF в модалке `#menu-modal`.
5. **Шаттл** — маршрут и расписание (блок 4.7).
6. **Афиша** — массив `AFISHA` в `js/app.js` (03–10 января сейчас пример).
7. Номера в карусели в рабочей версии брать из TravelLine (сейчас 6 категорий с текущего сайта).

## Вариант B — постерный стиль (`v2/`)
Альтернативный макет того же ТЗ: кремовый фон, кобальтовый синий + красно-оранжевый, крупная гротескная
типографика (Inter Tight), фото в кругах/арках, вырезанные фигуры поверх цветных форм.
- Открыть: `http://localhost:8765/v2/` (или `/v2/?clean`). Pages: `/kamenniy-cvetok-ny2027/v2/`.
- Контент, ссылки TravelLine, цели аналитики, афиша — те же, что в варианте A (`v2/js/app.js`).
- Фото берутся из общей папки `img/`; в `v2/img/cut-*.webp` — фигуры, вырезанные из временных фото Commons
  (те же лицензии, см. `credits.html`). При замене фото на материалы заказчика вырезки нужно сделать заново.
